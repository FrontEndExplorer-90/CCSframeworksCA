# CCSframeworksCA

This project is a responsive social media app layout built using **Bootstrap 5** and **Sass**, as part of the CSS Frameworks course assignment.

## Pages included
- `/index.html` – Authentication page with form validation
- `/feed/index.html` – Feed with posts, search bar, and sort options
- `/profile/index.html` – User profile with avatar, posts, and follower stats
